# Geek-Txt-Reader

极简纯净的 VS Code 状态栏隐蔽阅读器。

专为开发者打造，利用有限的状态栏横向空间实现丝滑连贯阅读，杜绝漏字、断层。

## ✨ 特性

- 📖 **智能编码与分章**：自动检测 UTF-8 与 GB18030/GBK 编码，拒绝乱码；支持常规网络小说分章。
- 🔄 **跨章平滑滚动**：前进到章末自动进入下一章，回退到章首自动衔接上一章末尾。
- 🔍 **章节快速检索**：使用快捷键秒级呼出类似代码搜索的跳转面板。
- 🛡️ **老板键伪装**：一键切换伪装字符或完全隐形。
- 🎯 **防误触设计**：状态栏文字纯展示，所有交互入口均收纳于鼠标悬浮卡片中。

## ⌨️ 快捷键

| 快捷键 | 功能 |
| :--- | :--- |
| `Alt + Right` | 向前翻页滚动 |
| `Alt + Left` | 向后翻页滚动（支持跨章回退） |
| `Alt + J` | 呼出章节与进度跳转搜索框 |
| `Alt + Q` | 老板键隐藏/伪装切换 |

## ⚙️ 设置项

可以在 VS Code 设置（`Ctrl + ,`）中搜索 `geekTxtReader` 进行个性化调整：
- `geekTxtReader.displayLength`：单次展示字数窗口宽度（默认 35）
- `geekTxtReader.stepLength`：每次按键移动的字数步长（默认 28）
- `geekTxtReader.showTitle`：是否在状态栏常驻长章节名（默认关闭进入精简模式）
- `geekTxtReader.bossMaskText`：老板键伪装文本内容
